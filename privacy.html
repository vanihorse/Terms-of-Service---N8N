Este aplicativo foi desenvolvido para automação pessoal/interna via n8n. Nós não coletamos, armazenamos ou compartilhamos dados pessoais de terceiros. Os dados de login do TikTok são utilizados exclusivamente para autenticação via OAuth e envio de vídeos do próprio usuário para a sua conta do TikTok, sem retenção de informações em servidores externos.
